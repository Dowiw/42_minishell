## Description

The projects goal is to build a functioning shell that copies a lot of functionalities from bash.
the functionality includes, but is not limited to working pipes, environment variables and navigating directories.


## Instructions

inside the root folder simply run

```bash
make
```

then inside the root folder simply run

```bash
./minishell
```
